# Brillen Voigt – Floating Liquid Designkonzept

`brillen-voigt-liquid-konzept.html` ist ein eigenständiger Prototyp (keine Abhängigkeiten außer Google Fonts),
der ein High-End „Floating Liquid“-Design für brillen-voigt.de zeigt und zehn konkrete
Optimierungsvorschläge mit Aufwand, Wirkung und Messgröße enthält.

Öffnen: Datei im Browser laden (Doppelklick genügt).

## Inhalt
- Hero mit Liquid-Canvas (Metaballs in Entspiegelungsfarben) und schwebenden Glaskarten
- Zehn Optimierungsvorschläge (Typografie, Glas-Komponenten, Motion, Conversion, Performance, Dark Mode …)
- Komponenten-Demo inkl. Filialfinder mit live berechnetem Öffnungszustand
- Spezifikation: Farb-Tokens, fluide Typo-Skala, Canvas-Code
- Umsetzungsplan nach Wirkung pro Aufwand
