Die Idee

Liquid ist der Hintergrund, Floating ist der Inhalt.

Zwei Ebenen, strikt getrennt. Unten eine langsam fließende Farbfläche, die die Marke trägt. Oben Glasflächen, die den Inhalt tragen und über der Fläche schweben. Der Inhalt bewegt sich nur, wenn der Besucher etwas tut: scrollt, hovert, tippt.

Ebene 1Liquid-Hintergrund

Was
Drei bis vier weiche Farbblobs (Metaballs) auf einem Canvas, stark weichgezeichnet.
Farben
Teal, Lilac, Aqua. Das ist der grün-violette Restreflex einer Superentspiegelung. Ein Detail, das nur ein Optiker so wählen würde.
Tempo
Eine Vollbewegung dauert 20 bis 40 Sekunden. Niemand soll die Bewegung bewusst sehen, nur spüren.
Kosten
Ein Canvas, kein Video. Bei Reduced Motion wird daraus ein statischer Verlauf.

Ebene 2Floating-Glas

Was
Navigation als schwebende Pille, Karten mit Blur-Hintergrund, 1px helle Innenkante, weicher Schatten nach unten.
Tiefe
Drei Höhenstufen: Fläche (0), Karte (1), Dialog (2). Jede Stufe hat ihren eigenen Blur- und Schattenwert.
Bewegung
Karten driften 10 bis 14px in 9 Sekunden. Hover hebt um 6px. Mehr nicht.
Regel
Maximal 6 Glasflächen gleichzeitig im Viewport, sonst leidet die Performance auf älteren Handys.
Optimierungsvorschläge

Zehn Entscheidungen, die den Unterschied machen.

Jede Karte zeigt die Maßnahme, die konkreten Regeln und den Aufwand. Die Reihenfolge ist keine Wertung.

Quick Win

Fluide Typografie statt Breakpoints

Schriftgrößen wachsen stufenlos mit der Viewport-Breite. Ein Headline-Sprung bei 768px wirkt billig.

  • Display-Schrift: geometrisch, runde Formen (Linsen, Fassungen)
  • Body: humanistische Sans, 65 Zeichen Zeilenbreite
  • Skala mit clamp(), siehe Spezifikation unten
Mittel

Liquid-Hintergrund als Markenebene

Canvas mit drei Blobs in Entspiegelungsfarben ersetzt Stockfotos im Hero.

  • Blur 40px, Sättigung 1.2, Opazität je Theme
  • Bewegung an Mausposition leicht gekoppelt (Faktor 0.05)
  • Fallback: statischer Verlauf bei Reduced Motion
Mittel

Glas-Komponentensystem

Ein Set aus Pille, Karte, Dialog und Leiste. Alles aus denselben Tokens.

  • backdrop-filter: blur(22px) saturate(1.6)
  • Innenkante 1px, 75% Weiß hell, 14% Weiß dunkel
  • Radius 22px außen, 14px innen
Quick Win

Drei Wege, sonst nichts

Hero zeigt genau drei Aktionen: Sehtest-Termin, Online-Hörtest, Filiale finden.

  • Primär-Button mit Verlauf Teal zu Lilac
  • Mobil: Termin-Button bleibt unten fixiert
  • Jede Aktion in maximal zwei Klicks erledigt
Groß

Produkte schweben frei

Fassungen auf transparentem Hintergrund, mit weichem Schatten, auf dem Liquid-Grund. Kein Produktfoto mit weißem Kasten.

  • PNG/WebP mit Alpha, 1600px, unter 120 KB
  • Farbvarianten per Tipp wechseln, Bild blendet 300ms
  • Hover kippt die Fassung 3 Grad (3D-Transform)
Mittel

Motion-Choreografie

Ein orchestrierter Moment beim Laden, danach Ruhe. Verstreute Effekte wirken generiert.

  • Hero: Text 0ms, Karten gestaffelt 120ms, Blobs 600ms
  • Scroll: Karten parallax maximal 24px
  • Alle Dauern aus einem Token-Set: 250 / 350 / 600ms
Quick Win

Vertrauensleiste mit echten Zahlen

1929, 6 Filialen, zwei Fachbereiche. Große Ziffern in der Display-Schrift, direkt unter dem Hero.

  • Nur belegbare Zahlen, keine Floskeln
  • Tabular-Nums, damit Ziffern bündig stehen
  • Optional: Bewertungen aus Google, live eingebunden
Mittel

Filialfinder als Glasraster

Sechs Kacheln, jede mit Öffnungszustand (offen / schließt bald / geschlossen) als Farbpunkt.

  • Zustand aus Öffnungszeiten berechnet, nicht gepflegt
  • Route per Tipp, Telefonnummer als kopierbarer Text
  • Reihenfolge nach Entfernung, wenn Standort erlaubt
Quick Win

Dark Mode aus denselben Tokens

Glas auf dunkler Tinte wirkt hochwertiger als auf Weiß. Beide Themes werden gleich sorgfältig gestaltet.

  • Blobs im Dark Mode 30 bis 38% Opazität
  • Akzente aufhellen, damit Kontrast AA bleibt
  • color-scheme: dark für native Controls
Groß

Performance-Budget

Glas und Blur kosten GPU. Ohne Budget ruckelt die Seite auf dem iPhone der Kundin.

  • LCP unter 2,5 s, CLS unter 0,1, INP unter 200 ms
  • Maximal 6 backdrop-filter-Flächen im Viewport
  • Canvas pausiert, wenn Tab unsichtbar (visibilitychange)

Liquid-Hintergrund (Canvas, 40 Zeilen)

const c = document.getElementById('liquid'), x = c.getContext('2d');
const blobs = [
  { col: 'var(--blob-a)', r: .38, sx: .00011, sy: .00009, px: 0.0, py: 1.7 },
  { col: 'var(--blob-b)', r: .34, sx: .00008, sy: .00012, px: 2.1, py: 0.4 },
  { col: 'var(--blob-c)', r: .30, sx: .00013, sy: .00007, px: 4.2, py: 3.1 },
];
function frame(t) {
  const w = c.width, h = c.height; x.clearRect(0, 0, w, h);
  for (const b of blobs) {
    const bx = w * (.5 + .38 * Math.sin(t * b.sx + b.px));
    const by = h * (.5 + .34 * Math.cos(t * b.sy + b.py));
    const g = x.createRadialGradient(bx, by, 0, bx, by, b.r * Math.min(w, h));
    g.addColorStop(0, color(b.col)); g.addColorStop(1, 'transparent');
    x.fillStyle = g; x.fillRect(0, 0, w, h);
  }
  if (!document.hidden) requestAnimationFrame(frame);
}
// CSS: #liquid { position: fixed; inset: 0; filter: blur(40px) saturate(1.2) }
// Reduced Motion: Canvas ausblenden, statischen Verlauf auf body setzen.
